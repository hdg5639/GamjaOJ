# Core A v2 — limited pilot content review

Decision: APPROVED_LIMITED_PILOT. Exact artifact hash and machine-readable decision are in
`core-a-v2-review.json`. Reviewer: AI-assisted content inspection in the authorized implementation
session, not an independent human educator or learner study. Operational release evidence belongs
only in docs/GamjaJudge_Implementation_Status.md.

## Review conclusions

- Statements define valid inputs, outputs and edge behavior. Public samples are the first fixed test.
  The v1 clock title suggested exactly one day; v2 changes it to elapsed minutes. New bank and all
  problem version IDs preserve the prior candidate and any historical snapshots.
- Independent review calculations reproduce all 53 fixed expected answers and check declared input
  constraints. Java reference execution and two wrong-solution families per question are separate
  evidence. They do not prove exhaustive correctness or calibrated difficulty.
- Implementation pair observes unit conversion and rejected state transitions. It does not establish
  general implementation ability. D=0, multiple-day rollover and rejected moves are explicit.
- Array/string pair observes consecutive-state resets, inclusive indexing and integer range. N,Q<=1000
  allows direct summation; prefix sums are optional. Do not penalize equivalent correct solutions.
- Data-structure pair observes duplicate handling and bracket nesting, including crossing types and
  unclosed stacks. A set/stack is a possible implementation, not a required interpretation.
- Search pair observes reachability and shortest unweighted grid paths. These tasks share a structure;
  the second benefits from transfer. Do not count them as independent evidence of a recurring habit.
- Workload uses short statements and bounded input (strings <=1000, grid <=20x20). Eight questions
  remain optional, selectable by pair, and pausable. No measured time promise is made. Search may
  exceed a beginner's idea of easy: difficulty labels remain provisional, not calibrated ranks.
- Content is generated by the local authoring builder from generic algorithm exercises. No external
  statement was imported in this review. This is not a claim that the concepts are novel or that an
  exhaustive similarity/licensing search has been performed.
- Public entry explicitly says pilot, provisional difficulty and unmeasured learning effect. Never
  describe this bank as all categories, mastery certification or validated psychometric measurement.

## Release checks

Staging stays `reviewed=false`. Release is a separate transaction generated from the exact reviewed
artifact and manifest. It verifies every pinned package, hash, rubric, category, difficulty, position,
runtime, policy, visibility and review hold before setting the bank flag. Mismatched content fails
closed. Private artifacts/references/mutants must stay outside frontend assets and public APIs.
