# GamjaOJ UI/UX 기준

## 기본 시각 언어: 글래스모피즘 + 뉴모피즘

앞으로 새 페이지·기능·모달을 만들거나 기존 화면을 수정할 때 반드시 현재 앱의 글래스모피즘과 뉴모피즘을 함께 반영한다. 사용자 요청에 따라 확정한 프로젝트 기본 디자인이며, 일반적인 UI 가이드의 평면형 기본값보다 우선한다.

- **표면:** 배경과 테마 색이 은은하게 비치는 반투명 표면과 backdrop blur를 사용한다. 단색 불투명 카드 위에 그림자만 붙이는 방식으로 대체하지 않는다.
- **입체감:** 눈에 띄는 테두리 대신 주변 색과 어울리는 얕은 양방향 그림자와 안쪽 그림자로 자연스럽게 높이를 표현한다. 검은 그림자·강한 흰 반사광·굵은 외곽선은 피한다.
- **버튼·선택 상태:** 판뿐 아니라 버튼, 드롭다운, 입력, 탭, 기능 모달 내부에도 같은 재질을 적용한다. 기본 버튼은 raised, 눌림·선택·입력은 inset으로 구분한다. 비활성 버튼의 입체감은 줄인다. 포커스 링은 접근성을 위해 명확하게 유지한다.
- **내부 목록:** 리스트·성장겹·보고서·표·내부 섹션까지 색과 투명도를 맞춘다. 항목마다 카드와 그림자를 중첩하지 않고 여백·정렬·옅은 구분으로 묶는다.
- **앱 경계:** 상단바·사이드바·내용의 경계를 진한 선이나 불투명 띠로 막지 않는다. 같은 테마 표면과 은은한 깊이로 구분한다.
- **배경:** 현재의 절제된 오로라 메쉬 그라데이션을 유지한다. 새 페이지에서 점 격자나 별도 강한 장식 배경을 도입하지 않는다.
- **테마:** light/dark와 사용자 HEX 설정을 모두 반영한다. `surface-theme.css` 및 기존 `--canvas`, `--surface`, `--ink`, `--subtle`, `--green`, 재질 토큰을 재사용한다. 특정 흰색·검은색을 기능 화면에 고정하지 않는다. blur 미지원 시 기존 불투명 fallback을 따른다.

## 화면 구성과 동작

정보와 핵심 행동을 먼저 배치하고 재질은 그 위에 적용한다. 데스크톱을 세로로 긴 모바일 카드 목록으로 만들지 않는다. 관련 선택/진행 정보는 한눈에 비교하고, 편집기·문제·실행 결과는 기존 크기 조절과 배치 기능을 보존한다. 긴 지난 기록은 별도 보기 또는 페이지네이션으로 분리한다.

공통 SelectControl·Modal·버튼·페이지네이션을 재사용한다. 드롭다운 화살표 여백을 유지하고 modal 안쪽 패딩을 충분히 준다. pending/오류/retry/비활성 상태를 표시하며 recoverable 오류에서 입력과 초안을 보존한다.

## 훈련 진입과 준비 상태

훈련 기록에 진입하면 현재 활성 훈련이 속한 코스를 우선 열고, 활성 문제 없이 이어가는 미완료 코스도 바로 보여준다. 저장된 다른 코스 선택보다 현재 진행 중인 코스가 우선한다. 진단 결과에서 학습 계획을 명시적으로 연 경우와 사용자가 선택한 탭은 늦게 도착한 조회 결과로 덮어쓰지 않는다.

진단 기반 학습 계획은 코스와 별도임을 설명하고, 기존 문제 자동 연결 → 필요한 생성·검증 → 풀이·제출 → 마무리·학습 확인을 안내한다. 생성 검증 실패를 수동 생성 요청으로 안내하지 않는다. 실패 시 기존 문제 재탐색과 수동 문제 연결을 제공하며, 실패한 유료 생성은 자동 재요청하지 않는다. 활성 훈련의 이어 풀기·마무리 컨트롤은 코스와 학습 계획 상단에서 제공한다. 기존 테마·재질·공통 컨트롤을 그대로 사용한다.

학습 계획 전체의 종료와 현재 문제 훈련의 마무리를 구분한다. 계획 종료는 미시작·준비 실패 상태에서도 제공하고, 해당 계획의 활성 세션만 마무리한다. 다른 코스와 자유 연습은 유지한다. 종료 시간·메모·기존 목표·제출을 보존하며 목표 달성으로 자동 판정하지 않는다. 종료된 계획의 새 회차·생성·문제 자동 준비는 서버에서도 차단한다. 종료된 계획은 `[종료]`로 표시하고 기록을 읽을 수 있게 유지한다.

## 마이페이지의 성장과 기록

마이페이지 상단의 `성장 현황 / 풀이 기록` 전환은 기록 새로고침 오른쪽에 compact control로 배치한다. 별도 설명 행 없이 제목과 같은 줄에 놓고, 모바일에서는 세 컨트롤을 동일 행에 배치한다.

마이페이지 기본 화면은 `성장 현황`이다. 성장 겹·풀이 잔디·유형 균형·다음 학습을 기존 2열 구조로 보여준다. 별도의 `풀이 기록`에서 `풀어본 문제 / 전체 제출`과 페이지네이션·회고·제출 상세를 제공한다. 성장 겹의 `내 풀이 기록`은 기록 탭으로 연결한다.

상위 탭 왕복 시 기록 종류·페이지·스크롤·잔디 날짜·유형 범위와 페이지를 유지한다. 기록 목록은 처음 열 때 조회하고, 동일 상태의 탭 왕복으로 재조회하지 않는다. 숨겨진 성장 영역의 조회는 실제 표시 시 갱신하며 제출·회고·새로고침으로 바뀐 상태를 반영한다. 상위 탭은 공통 glass/raised/inset 재질과 사용자 테마를 사용하며 키보드로 선택할 수 있다.

## 테마 설정의 스크롤 성능

화면 설정은 고정된 반투명 shell과 내부 설정 스크롤 영역을 분리한다. 제목·닫기 버튼·영역 선택 메뉴를 유지하고 `.appearance-content`만 스크롤한다. 이 팝업과 backdrop에는 live backdrop blur를 사용하지 않는다. 대신 테마에 맞는 반투명 패널과 공통 relief 그림자로 기존 glass/neumorphism 인상을 유지한다. 다른 팝업의 재질 정책은 유지한다.

내부 스크롤의 layout/paint를 격리하고 배경으로 scroll chain이 전달되지 않게 한다. 모바일에서는 영역 선택을 상단에 배치한다. 색·글꼴 실시간 반영, 저장·재시작 복원, 편집기 인스턴스와 undo, 키보드 포커스 및 Escape를 유지한다. 크롬 CPU throttle 측정과 실제 Windows/GPU 검증은 구분한다.

## 검증 기준

새 구조는 최소 390px·중간 화면·1440px에서 확인한다. light/dark 및 사용자 테마, 가로 넘침, 긴 제목·본문·API 계약·그림, 키보드 포커스/Escape, 선택 상태를 확인한다. 시각 변경 중 초안·편집기 undo·제출·진단 상태·권한·멱등성은 유지한다. 애니메이션은 기존 motion과 reduced-motion을 따른다.
