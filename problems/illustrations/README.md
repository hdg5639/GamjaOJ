# 문제 이해 그림

공개 일반 문제 492개를 대상으로 그림 필요성을 분류했다. `review-v1.csv`의 `ILLUSTRATED`는 본문 규칙을 검토하고 그림을 연결한 26개다. 그중 추가한 12개는 관련 본문 문단 직후에 배치하고, 그림 아래에 설명이 이어지도록 구성했다. 추가 후보 43개는 아직 개별 검토 전이다. `REVIEW_NEEDED`는 구조 관련 단어를 포함한 후보이며 아직 개별 제작 승인을 의미하지 않는다. `TEXT_FIRST`도 그림이 불필요하다는 확정 판정은 아니다.

그림은 격자·방향·연결·좌표·물체의 배치와 규칙을 설명한다. 최적 경로, 벽의 정답 위치, 최소 비용 연결, 비공개 테스트나 정답 코드가 포함된 그림은 제작하지 않는다. 공개 예제의 계산 과정도 원칙적으로 그림에 넣지 않으며, 명령 처리 문제만 삽입·삭제·예약 등 상태 변화 예시를 사용할 수 있다.

제목보다 실제 규칙을 따른다. 예를 들어 ‘되돌리기 가능한 문서 편집기’에는 실제로 UNDO 명령이 없으므로 커서 기반 TYPE·DELETE만 그렸다. ‘암호문 삽입과 삭제’는 인덱스 문구가 모호해 이번 그림 대상에서 제외했다.

`reviewed-statements-v1.json`은 검토한 원문의 해시다. 공개 메타데이터 목록을 입력으로 `python3 scripts/build-problem-illustrations.py /path/to/public-statements.json`을 실행한다. 목록은 `{version,title,category,statement}` 배열이며 채점 패키지는 입력하지 않는다. 본문이 달라지면 빌드가 중단된다. 새 규칙을 다시 검토한 뒤 검토 해시를 갱신해야 한다.

생성된 SVG는 `frontend/public/problem-illustrations/`에, 버전·본문 해시와 대체 설명을 담은 연결 정보는 `backend/src/main/resources/problem-illustrations-v1.json`에 저장된다. 서비스도 본문 해시가 맞는 그림만 노출한다. 원문·채점 패키지·패키지 해시는 수정하지 않는다.

## 내가 만든 문제의 그림

풀이 화면의 **문제 그림 관리**에서 PNG/JPEG를 선택하거나 붙여넣고, 그림 설명과 선택 캡션을 적는다. 검증을 마친 본인 일반 문제에만 추가·삭제할 수 있다. 한 파일 3 MiB, 한 문제 8개이며 가로·세로 5000픽셀과 전체 800만 픽셀 제한이 있다. 서버가 PNG로 다시 인코딩하며 원본 파일 메타데이터를 제거한다.

공유한 문제의 그림은 다른 회원도 볼 수 있고, 비공개 문제의 그림은 소유자만 볼 수 있다. 이미지 주소도 같은 접근 권한을 확인한다. 그림은 눌러 확대할 수 있다.

본문은 Markdown을 지원한다. 등록한 그림의 주소를 `![격자의 벽과 이동 방향](/api/problem-images/<그림 UUID>)`로 넣어 본문 중간에도 표시할 수 있다. 임의 외부 이미지 주소와 HTML은 렌더링하지 않는다. 문서의 설명은 이미지 없이도 읽을 수 있게 유지한다.

## 본문 중간 삽입

12개 추가 그림의 manifest에는 `afterParagraph`와 `explanation`이 있다. `afterParagraph`는 실제 검토한 원문의 완전한 문단이며, `explanation`은 그림 바로 아래에서 이어지는 공개용 설명이다. 채점 패키지를 수정하지 않고 표현 계층에서만 **원문 문단 → 그림 → 설명 → 다음 원문 문단**으로 연결한다.

공통 renderer는 Markdown 문법 트리의 최상위 문단을 정확히 비교한다. 코드 블록·목록·인용문 안에는 끼워 넣지 않는다. 같은 문단이 둘 이상이면 위치를 추측하지 않고 기존 첨부 영역에 보여준다. 원문에 이미 등록 이미지가 직접 또는 참조 형식으로 들어 있다면 아래 첨부 영역에 중복 표시하지 않는다. 그림 확대와 읽기 순서, 원문의 입력·출력·제약은 그대로 유지한다.

추가 대상: 한 박자 늦게 열리는 문, 빌린 날개 한 번, 금이 간 유리섬, 유리섬의 마지막 다리, 색종이 쿼드트리, 단지 번호 붙이기, 다리 위의 트럭 하중 제어, 감시카메라 배치, 불과 비상탈출, 격자 도미노 비트마스크, 0-1 BFS 격자 탈출, 작업 순서 결정.
